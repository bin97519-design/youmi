主图视频2、Agent记忆与按次视频模型升级

新增主图视频2与商品卖点分析流程，完善Agent上下文记忆、完整脚本和参考图设置，接入SD 2.0按次视频模型并修复失败后的重试入口。

主图视频策划与制作

  • 新增独立主图视频2入口，结合商品资料、参考图和五维策略策划完整脚本；镜头数量与每镜秒数依据内容和节奏安排。
  • 主图视频支持先分析主图或详情页中的商品卖点，确认后再添加视频画面参考图和创作要求。
  • 支持直接使用已有参考图生成整片，补齐声音、模型和版本设置，压缩时间轴与参考图区域的空白。
  • 参考视频复刻分别保留商品外观、人物场景与原片节奏要求，视频结果与费用确认进度分开展示。

Agent对话与提示词

  • 接入GEM 3 Pro并同步策划模型选项，完善Gemini原生协议、错误识别和流式回复。
  • 上下文预算默认100K，较早对话压缩为可持久保存的摘要，保留近期正文、完整方案及用户给定的创作规格。
  • 延长模型等待时间至30分钟，补充上下文用量、消息时间和等待状态；识别不完整回复并尝试重新整理完整脚本。
  • 图片方案可调整多个模型、比例、清晰度和数量，确认生成时携带所选原始参考图；提示词库增加视频分类。
  • 将上游内容拦截明确显示为失败原因，避免保存为视频提示词；确认视频任务失败后恢复手动重试入口并保留原图和脚本。

视频模型与稳定性

  • 新增SD 2.0按次模型，支持快速与标准版本、4至15秒、720p及最多9张参考图，固定生成有声视频。
  • 使用独立任务创建与查询协议，按终态字段判断结果，查询沿用提交时的密钥，并按上游实际费用结算。
  • 按次模型设置根据能力同步校验，完善窄窗口中的速度选择和说明布局；失败不会自动重新提交付费任务。
  • 整合新版画布的商品创作、素材工作室与对话任务路由更新；移除旧版V2入口，原地址返回画布列表。

  • 接入 gpt-5.6-luna 作为 Agent 语言与视觉理解模型，根据是否提交参考图决定是否进行识图分析。
  • Agent 先与用户沟通、补充方案和优化提示词，只有用户点击“确认生图”后才会提交生成任务。
  • 输入区新增增强提示词按钮，可直接润色当前文字并回填，不会自动发送或触发生图。
  • 新增独立会话、历史会话搜索与删除，并保持同一会话内的上下文连续。

提示词体验

  • 用户要求多条提示词时，按数量生成彼此独立的完整方案，可切换、复制并分别确认生图。
  • 提示词正文自动按语义分段，优化卡片宽度、行距、留白和滚动区域，深浅主题下都更容易阅读。
  • 增强 Agent 返回格式的容错与一次自动修复，避免多方案结果因尾逗号等格式问题反复显示失败提示。
  • 历史上下文会跳过解析失败的固定提示，避免错误回复在会话中循环出现。

画布能力

  • 激活智能抠图入口，复用现有 banana2 生图通道生成干净背景结果，并展示任务状态。
  • 参考图参与生成时自动建立来源连接线，生成比例优先跟随参考图，图层列表默认展示每张图片尺寸。
  • 修复宫格裁图选择、拖动响应和处理中状态，并优化生成图片、提示词与画布操作之间的交互冲突。
  • 画布创作、普通生图和对话修改继续复用现有模型、比例、分辨率与多模型并行生成体系。
